## Objective
Remove all audio from the app: spoken winner announcements (Web Speech API), all synthesized WebAudio sound effects (move ticks, win/draw fanfares, la-la-la jingle, slide whistle), and the mute toggle in the top bar.

## Background
User feedback: the voice announcement felt like a "mute celebration" even after a hype pass (#13). Decision: remove audio entirely rather than keep tuning it.

## Functional Requirements
- No audio of any kind plays at any point (moves, wins, draws, match wins).
- Mute/unmute button removed from the top bar (nothing left to mute).
- Visual celebrations (confetti cannons, emoji rain, result overlays) are unchanged.
- Delete `src/game/sound.ts`, `src/game/voice.ts`, `src/game/voice.test.ts` and all call sites.

## Acceptance Criteria
- [ ] No imports/references to sound or voice modules remain.
- [ ] No mute control in the UI.
- [ ] Tests, lint, and build pass.
- [ ] README updated (no sound/voice feature claims).

## Testing
- `npm run test`, `npm run lint`, `npm run build`
